================================================================================
                         BILLING CALCULATION FLOW
================================================================================

Input Data:
  Previous Reading: 1,000 cu.m
  Current Reading:  1,050 cu.m

                          ↓

Auto-Calculate Consumption:
  Consumption = 1,050 - 1,000 = 50 cu.m

                          ↓

Calculate Bill Amount:
  Bill = 50 cu.m × 200 KES/cu.m = 10,000 KES

                          ↓

Calculate Penalty (if applicable):
  If (today > penalty_date):
    Days Overdue = today - penalty_date
    Penalty = Days Overdue × 5 KES
  Else:
    Penalty = 0

                          ↓

Total Payable Amount:
  Total = Bill + Penalty
  Total = 10,000 + Penalty


================================================================================
                          ADMIN USER ACTIONS
================================================================================

1. NAVIGATE TO DASHBOARD
   Sidebar: Bills > Meter Readings
   OR Direct URL: /meter-readings/

2. SEARCH/FILTER CUSTOMERS
   - Type in search box (name/meter/phone)
   - Select status filter
   - View filtered results

3. ADD METER READING
   - Click [+] button on customer row
   - Enter current meter reading
   - Review auto-calculated consumption
   - Set dates and payment status
   - Click "Save Reading"
   - Bill created automatically
   - SMS notification sent to customer

4. REVIEW READING HISTORY
   - Click [⏱] button on customer row
   - See all past readings and bills
   - View consumption trends
   - Access edit functionality

5. EDIT EXISTING READING
   - Click [✎] button
   - Modify any field
   - Recalculates automatically
   - Save changes
